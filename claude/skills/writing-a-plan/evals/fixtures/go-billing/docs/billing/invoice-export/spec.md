# 發票批次匯出

## 概述

讓後台使用者可以選定一個月份，把該月份底下所有發票一次打包成 zip 下載，取代目前一張一張點下載的流程。

## 背景與問題

目前後台的發票列表只提供單張 PDF 下載。會計每月結帳時平均要點擊 60～200 次才能收齊當月發票，客服每週固定收到 3～5 則相關抱怨。已確認這是本季客服工單量第二高的來源。

## 目標

- 使用者可用一次操作取得整月發票，取代逐張下載
- 當月 200 張發票的匯出，從送出到可下載不超過 3 分鐘
- 上線一個月後，相關客服工單降至每週 1 則以下

## 非目標（範圍外）

- 不做跨月份／自訂日期區間匯出（本次僅支援單一自然月）
- 不做 Excel／CSV 格式匯出
- 不做排程自動匯出與 email 寄送

## 使用者與情境

- **作為** 租戶的會計人員，**我想要** 一次下載整月發票，**以便** 月結時不用重複點擊數百次
- **作為** 客服，**我想要** 引導客戶自助匯出，**以便** 減少代為手動打包的工單

## 功能需求

| 編號 | 優先級 | 需求描述 |
|------|--------|----------|
| FR-1 | P0 | 使用者可指定年月，對該租戶該月份的所有發票發起匯出，系統回傳一個匯出任務識別碼 |
| FR-2 | P0 | 匯出以非同步方式進行，使用者可查詢任務狀態（pending／processing／done／failed） |
| FR-3 | P0 | 任務完成後，使用者可透過該識別碼取得一個 zip 下載連結，內含該月份所有發票 PDF |
| FR-4 | P0 | 匯出範圍僅限發起者所屬租戶的發票，不得跨租戶取得資料 |
| FR-5 | P1 | 同一租戶同一月份若已有進行中的匯出任務，重複發起時回傳既有任務而非建立新任務 |
| FR-6 | P1 | 下載連結具時效性，逾期後失效 |
| FR-7 | P2 | 匯出完成時在後台顯示通知 |

## 非功能需求

- **效能**：200 張發票的匯出需在 3 分鐘內完成
- **安全**：下載連結不得可被猜測；任務狀態查詢需驗證租戶歸屬
- **可觀測性**：匯出任務的成功／失敗率與耗時需可被監控

## 驗收標準

- [ ] FR-1：Given 租戶有 2026-05 的發票，When 發起該月份匯出，Then 回傳 202 與任務識別碼
- [ ] FR-2：Given 已建立的匯出任務，When 查詢任務狀態，Then 回傳當前狀態值
- [ ] FR-3：Given 任務狀態為 done，When 取得下載連結，Then 下載到的 zip 內含該月份全部發票 PDF
- [ ] FR-4：Given 任務屬於租戶 A，When 租戶 B 查詢該任務，Then 回傳 404
- [ ] FR-5：Given 同月份已有 processing 任務，When 再次發起匯出，Then 回傳既有任務識別碼
- [ ] FR-6：Given 下載連結已逾期，When 存取該連結，Then 拒絕下載

## 相依與風險

- **相依**：發票 PDF 已存在於物件儲存；匯出結果需要一個可存放 zip 的位置
- **假設**：單一租戶單月發票數量不超過 1000 張
- **風險**：大量並行匯出可能壓垮儲存頻寬 → 需限制同時進行的任務數
