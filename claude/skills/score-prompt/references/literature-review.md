# 情境：文獻整理與資料綜整

適用於論文文獻回顧、競品比較、市場調查綜整、技術選型的資料彙整——**產出物是把多份來源整理成可比較的結構，而且必須可追溯回原文。**

這個情境與資料分析的差別在於：分析要下判斷，綜整要**克制判斷**。使用者要的是把散落的東西排整齊，好讓他自己看出結論，而不是替他下結論。

## 這個情境的五維重心

| 維度 | 在這類任務裡特別重要的原因 |
|---|---|
| **S** | 來源的數量、類型與領域決定了比較的粒度。五篇論文和五十篇的整理方式完全不同 |
| **C** | 「研究助理」這個角色設定的核心是**只提煉不評論**，這正是它與分析師的分野 |
| **O** | 通常是一個具體的比較問題（有沒有共識、差異在哪、缺口在哪），不是「整理好」 |
| **R** | 幾乎都是表格，而**欄位定義就是整份工作的設計**。欄位選錯，整理再仔細也沒用 |
| **E** | **這個情境的最高風險是幻覺引用。**頁碼與原句必須有明確的「找不到就標註」條款 |

**這個情境有一個獨特的張力：Objective 要求回答一個問題（例如「有沒有共識」），Exactness 卻要求不主觀評論。**兩者不衝突，但要在 prompt 裡講清楚界線：陳述「三篇採用 X 方法、兩篇採用 Y」是事實整理；說「X 方法比較嚴謹」就越界了。這條界線值得在限制條件裡明寫。

## 問答選項設計要點

**目標那題**要拉出不同的比較問題，因為它決定表格欄位：

- A（推薦）釐清這幾份來源之間有沒有共識，共識在哪、分歧在哪
- B 找出現有研究的缺口，作為自己研究的切入點
- C 建立方法論的對照，決定自己要採用哪一種

選 A 的表格會有「立場／結論」欄，選 B 會有「未處理的問題」欄，選 C 會有「方法適用條件」欄——同樣五篇文獻，三種完全不同的表。

**產出那題**的選項直接就是欄位組合，不要只問「要不要表格」：

- A（推薦）作者、核心論點、研究方法、與其他文獻的關係
- B 作者、年份、樣本與資料來源、主要發現、限制
- C 依主題分群，每群下列出支持與反對的文獻

**限制那題**的核心是可追溯性與克制：

- A（推薦）不主觀評論，僅整理事實；引用時附上原句與頁碼；找不到明確出處時標註「原文未明確陳述」而非改寫
- B 允許在表格後另闢一段標明「整理者觀察」，但須與事實區隔
- C 需同時標註每個論點在原文中的章節位置，供後續查證

## 完整範例

### 原始需求
> 幫我整理一下這五篇文獻

### SCORE 拆解

| 維度 | 內容 |
|---|---|
| **S** 情境 | 正在寫論文，已蒐集五篇文獻，需要在寫作前先確認它們之間的關係 |
| **C** 角色 | 學術研究助理，擅長提煉論點，只整理不評論 |
| **O** 目標 | 釐清這五篇文獻之間有沒有共識，共識在哪、分歧在哪 |
| **R** 產出 | 文獻比較表：作者、核心主題、研究方法、與其他文獻之間的關係 |
| **E** 限制 | 不主觀評論，僅整理事實；引用時附上文獻原句與頁碼 |

### 成品 Prompt

```
## 情境
我正在寫論文，已經蒐集了五篇相關文獻。在開始寫作之前，我需要先弄清楚這五篇之間的關係——它們是互相支持、互相反駁，還是在講不同層次的問題。

## 你的角色
你是一位學術研究助理，擅長從長篇論文中提煉出核心論點。你的專業紀律是**只整理不評論**：你負責把每篇說了什麼、怎麼說的忠實呈現出來，判斷高下是研究者自己的工作。

## 任務目標
釐清這五篇文獻之間有沒有共識。具體來說，我要能看出：哪些論點是多篇共同支持的、哪些地方彼此分歧、分歧的根源是研究方法不同還是立場不同。

## 輸出要求
產出一張文獻比較表，欄位依序為：
1. **作者（年份）**
2. **核心主題** — 這篇要回答的問題與它的主要主張，兩三句話
3. **研究方法** — 資料來源、樣本、分析方式
4. **與其他文獻的關係** — 明確指出支持／反駁／補充了表中哪一篇，或標註「無直接關聯」

表格之後，另列一段「共識與分歧」，僅以條列方式陳述事實：哪幾篇在哪一點上一致、哪幾篇在哪一點上不同。

## 限制條件
- 不做主觀評論。可以陳述「三篇採用量化方法、兩篇採用個案研究」，但不可寫「量化方法較為嚴謹」
- 每個核心論點都要附上文獻中的原句與頁碼，格式為：「原句」（作者, 年份, p. XX）
- **如果找不到明確的原句或頁碼，直接標註「原文未明確陳述」或「頁碼待補」，絕對不要改寫成看似精確的引用或推測頁碼。**寧可空著讓我查，也不要編造
- 若某篇文獻的立場需要跨段落推論才能得出，在該格標註「（推論自 pp. XX–XX）」，與直接引用區隔開
- 全文繁體中文；文獻標題、專有名詞與引用原句保留原文語言
```

### 自檢

- ✅ **Objective ≠ Result**：O 是「看出共識與分歧的所在」這個認知結果，R 是四欄比較表加一段條列
- ✅ **Exactness 可驗證**：有無評論性形容詞、每個論點有無頁碼、有無使用「原文未明確陳述」標註，都能逐條核對
- ✅ **Character 有作用**：換成「論文審查委員」會產出評價與批判，與整理表完全不同
- ✅ **Result 有骨架**：四個欄位都有明確定義，第四欄還指定了要對照表中哪一篇
- ⚠️ **五維無矛盾（O 與 E 有張力，已處理）**：O 要求回答「有沒有共識」，E 要求不評論。我在限制條件裡用「可以陳述方法分佈、不可評價方法優劣」把界線舉例化了，但實際使用時仍可能出現灰色地帶，建議第一次產出後檢查一遍「共識與分歧」那段有沒有夾帶價值判斷
- ⚠️ **Situation 未說明領域**：不同學科對「核心主題」的粒度期待不同（實證研究 vs 理論文章）。補上學科與論文主題會讓提煉更準

## 這個情境的常見陷阱

**幻覺引用是這個情境最嚴重的風險，而且它偽裝得最好。**模型很樂意產出「（Smith, 2021, p. 47）」這種看起來完全正確的引用——頁碼可能是編的。這條限制不能省，而且要寫得夠強硬：明確告訴它「寧可空著，不要編造」，並給一個具體的替代標註方式（「原文未明確陳述」），它才有台階可下。沒有替代方案的禁令，模型傾向偷偷違反。

**「整理好」不是 Objective。**如果使用者說不出他想從這批資料裡看出什麼，表格欄位就沒有依據，最後會得到一張很整齊但用不上的表。追問「你整理完之後要拿它做什麼」——是要找研究缺口、要決定方法、還是要在論文裡寫一段文獻回顧？答案直接決定欄位。

**欄位定義比欄位名稱重要。**「核心主題」四個字，不同人會填出完全不同粒度的東西。在 Result 裡把每個欄位要放什麼、寫多長都講清楚，這是這類任務投報率最高的一步。

**要區分「直接引用」與「推論」。**文獻的立場常常不是某一句話直接說的，而是要從整篇推論。強制模型標註哪些是原句、哪些是推論，能讓使用者知道哪幾格需要自己回頭確認。
